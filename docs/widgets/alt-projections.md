# `alt-projections`
Alternating minimization of the KL divergence between two curves $K$ and $S$ of the three-outcome probability simplex (`js/widgets/alt-projections.js`; svg + plain HTML; reuses the triangle and $D_{KL}$ of `simplex-points`). Argument order always $D[P:Q]$, $P\in K$, $Q\in S$. From a start $Q_0\in S$: $P_t=\arg\min_{P\in K}D[P:Q_t]$ (first argument free; connecting curve $Q_t\to P_t$ is the exponential curve $q^{1-s}p^s/Z$), then $Q_{t+1}=\arg\min_{Q\in S}D[P_t:Q]$ (second argument free; connecting curve $P_t\to Q_{t+1}$ is the straight mixture segment). So $D[P_{t-1}:Q_t]\ge D[P_t:Q_t]\ge D[P_t:Q_{t+1}]$. Projections are numerical (dense grid over the curve parameter, then golden section; checked against a 40000-point grid and against orthogonality $\sum_i\dot P_i\ln(P_i/Q_i)=0$, $\sum_iP_i\dot Q_i/Q_i=0$ at the feet, $<10^{-4}$). Buttons Step, Run (animated), Reset; the zigzag is drawn with numbered points $P_0,Q_1,\dots$; a table with bars lists $D$ after every step; a small corner marker at each foot (its sides lie along the two curves; on screen it is not $90^\circ$, the triangle is not drawn in the Fisher metric). General tool, no course text.
Config: `outcomes`; `K`, `S` = a set each (+ `name`, `hue`: vec / covec by default): `{type: mixture, a, b, t?}` ($p=(1-t)a+tb$; default $t$: the longest interval keeping all components $\ge0.004$, so a whole chord of the triangle), `{type: exponential, a, b, t?}` ($p_i\propto a_ie^{tb_i}$, default $t\in[-1,1]$), `{type: arc, center, r, from, to}` (circle of radius $r$ in the plane $\sum p_i=1$, degrees; $0$ to $360$ = closed loop), `{type: curve, ps: [[..],..]}` (polyline); `start: [p1,p2,p3]` ($Q_0$, moved to the nearest point of $S$), `draggableStart` (drag $Q_0$ along $S$, resets the path); `names: {K: P, S: Q}`; `steps: 12` (max number of projections, each of $P$ or $Q$ counts one); `done: 0` (projections already made on opening: picture presets); `showD` (default true), `showFoot` (true), `showConnectors` (true; false = straight dashed segments), `showMin` (false: mark and print the closest pair of $K$ and $S$ found by grid search + 40 alternations, the dotted rings); `hide: [buttons, table, tags, feet, path, labels]`; `speed` (ms per step of Run, 550); `labels: {step, run, reset, start, min}`. Stops by itself when $D$ no longer decreases (Step disabled, "settled" line). Point labels are thinned after 8 points (first and last four stay).
`el.dataset`: `pts` (`P0:p1,p2,p3 | Q1:... `), `d` (the divergences, comma-joined), `steps`, `min`.
Presets (copy into the lesson; numbers from the widget, checked by script):

- `line-and-exp`: `{outcomes: [a, b, c], K: {type: mixture, a: [0.55, 0.4, 0.05], b: [0.3, 0.5, 0.2]}, S: {type: exponential, a: [0.35, 0.2, 0.45], b: [-0.9, 0, 0.9], t: [-1, 1]}, start: [0.55, 0.15, 0.3], showMin: true}`: $D=0.1864,\,0.1832,\,0.1813,\,0.1801,\,0.1794,\,0.1790,\dots\to0.1784$; $D[K:S]=0.1784$ (a mixture line and an exponential curve).
- `converge-local` (start decides the limit; two widgets, same config except `start`): `{outcomes: [a, b, c], K: {type: mixture, a: [0.46, 0.37, 0.17], b: [0.38, 0.36, 0.26], t: [-1.4, 1.4]}, S: {type: arc, center: [0.444, 0.346, 0.21], r: 0.17, from: 282, to: 582}, steps: 20}`; `start: [0.5134, 0.2072, 0.2794]` stops at $D=0.00397$ ($P$ stuck at the end of $K$, $(0.348,0.356,0.296)$; $D=0.0643,0.0199,0.0120,0.0048,0.0040,0.0040$), `start: [0.5332, 0.3935, 0.0733]` reaches the crossing $K\cap S=(0.543,0.380,0.076)$, $D\to0$ ($0.00035,\,0.00002,\dots$). A random search over about $10^4$ pairs of full mixture lines / exponential curves found **no** start-dependent limit with smooth interior feet (the limit is unique there, as the book says for flat/dual-flat sets); the example is therefore a finite segment (the trap is its end) and an arc.
